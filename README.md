# Launchpad Project

A community-focused web application developed for the UEA Launchpad Project.

## About

HelpingHand Ladywood is designed to connect local residents and volunteers, allowing users to request help, volunteer for community tasks, and support local projects.

## Technologies

- Node.js
- Express.js
- PostgreSQL (Supabase)
- HTML, CSS, JavaScript

*Created as part of a first-year Computer Science group project.*
